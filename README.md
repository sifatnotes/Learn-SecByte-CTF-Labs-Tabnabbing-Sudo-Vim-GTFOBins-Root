## Learning Path

A practical progression through this collection:

1. **Understand tabnabbing basics**  
   Start with Blank Tab, Bad News and Sleepy Tabnabbing 2 to recognize the core web-security theme.

2. **Study investigation and access**  
   Continue with Tabnabbing Trails and Tabnapped Access.

3. **Learn defensive concepts**  
   Complete Sleepy Tabnabbing Defenses and connect offensive observations with appropriate browser and application defenses.

4. **Explore admin breakout scenarios**  
   Work through Sleeping Admin Escape and Sleepy Admin Rooted Shell.

5. **Practice Linux privilege boundaries**  
   Study Sudo Snooze and examine how sudo configuration affects security.

6. **Connect Vim and GTFOBins**  
   Finish with Vim Got Root and GTFOBins Sleepy Sudo Escapes.

7. **Complete the user-level objective**  
   Use Napping the User Flag as a practical CTF progression challenge.

## How to Use the Labs

- Use every lab only in an authorized CTF or cybersecurity training environment.
- Start with reconnaissance and understand the challenge context before testing access paths.
- For tabnabbing labs, study both the attack concept and the corresponding defensive controls.
- Treat administrator, root, and user-flag scenarios as controlled training objectives.
- When studying sudo, Vim, or GTFOBins, focus on why the configuration or binary behavior creates a security boundary issue.
- Document findings and record defensive recommendations after each challenge.
- Never apply these techniques to systems without explicit authorization.
